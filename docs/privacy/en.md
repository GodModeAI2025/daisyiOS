## Local analysis of your files

OrbitDisk analyses folders that you explicitly select through the native document picker. The app uses the access granted by the operating system and file provider. It cannot freely search the entire iPhone file system or other apps’ private data.

For storage analysis, the app processes file and folder names, locations, file sizes and directory structure locally. Duplicate detection reads file contents and calculates SHA-256 hashes locally. Modification timestamps and other file metadata help recheck files before removal. Cleanup detection evaluates names and locations for possible temporary files, logs, caches or other disposable content.

OrbitDisk does not transmit file contents, hashes or analysis results to us or to a dedicated analysis server. We do not gain access to your selected files through the app. This processing serves only the analysis, preview and file actions that you initiate.

## Information stored locally

OrbitDisk stores the names of recently analysed folders and operating-system references to those folders in its local app settings. This lets you select a folder again if the file provider still permits access. The app does not store a complete copy of your folders for this purpose.

Analysis results and duplicate hashes are not saved as a persistent analysis database. They are processed in memory during use. Local folder references persist across app launches. They are removed when you delete the app and its data; merely offloading the app may retain its data. Backups and any restoration of app data depend on your Apple and device settings.

Deleting the app does not automatically delete files in the selected folders.

## iCloud Drive, other file providers and external drives

You can select local folders, available cloud folders or connected drives. Cloud file providers may download files for analysis or preview. Changes and deletions may be synchronised with other devices by the provider.

These transfers are performed by the service you use. Its own privacy information and your settings govern its processing, storage and any international data transfers. OrbitDisk does not operate its own cloud storage or upload your files to a MOBILE BOX server.

## Preview and deletion

File previews use Apple’s Quick Look functionality where the file format is supported. To show a storage location, OrbitDisk opens the native document picker; the provider may influence which location is displayed.

OrbitDisk deletes files or folders only after your explicit confirmation. Cleanup candidates and duplicates are not removed automatically. In synchronised folders, a confirmed deletion may also affect copies on other devices. Recovery depends on the operating system or file provider.

## No accounts, advertising or tracking in the app

OrbitDisk does not require a user account. The app contains no advertising, tracking or analytics SDKs and does not create advertising profiles. Analysis results are not sold or shared for marketing. OrbitDisk does not use its own cookies.

Apple may process data in connection with the App Store, TestFlight or your diagnostic settings under Apple’s privacy information. These platform services are separate from OrbitDisk’s local file analysis.
