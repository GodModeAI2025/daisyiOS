OrbitDisk is a native SwiftUI storage analyzer for iPhone and iPad, requiring iOS 27. No account or sign-in is required.

To test: on launch choose Ordner oder Datenträger wählen and grant a folder through Apple's document picker. During scanning, progress counts, elapsed time and cancellation are available. Results open automatically. Tap folder segments or folder rows to open subfolders; the orb center returns to the previous view. Files and the separate folder-actions button show file actions. Folder rows always appear before files. Small diagram segments are neutral; the file list retains every readable entry. There is no hard file-count limit. Unreadable entries are reported as an incomplete analysis.

The app analyzes only directories expressly selected via the system picker. It does not scan other apps' private data or the entire device. In Dateien anzeigen presents the native document picker with a directory hint; providers may ignore the hint. Quick Look appears only for supported files. Deletion requires an explicit confirmation, is scoped to the analyzed directory, and protects the analysis root and internal app settings.

External USB storage is optional, not required. The user can test with local files. The interface follows system light/dark appearance and Reduce Motion.

Please review this version normally. Release should remain manual.

Folder tools: Ordner prüfen → Aufräumkandidaten finden lists possible disposable data recursively, without preselection. Duplikate finden compares complete file bytes with SHA-256 via Apple's CryptoKit (hashing only; no encryption implementation). Choose a retained copy, then confirm removal of other copies. Both copies are revalidated immediately before deletion. No app account is required.

Build 5: Cleanup candidates → Funde auswählen enables multi-selection and Alle Funde auswählen. The bottom bar shows selected count/size and opens a shared deletion confirmation. Folder lists offer the same selection for visible search/filter matches. Deletion remains scoped and protects the analysis root. Action buttons use consistent full-width rounded rows.
